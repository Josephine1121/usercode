# [Josephine Gendill]
## [Just Study!]
## [ The purpose of this program is to store user created flashcards that can then be called on at a later time to be studied. The user will be able to create flashcards for different topics. Each flashcard will ask the user for a question, the answer, and the topic to which the desired flashcard should be stored. ]

---

## checkpoint-01: Initial project structure / setup

1. What challenges did you encounter?

The main challenge I faced during this stage of the program was navigating through GitHub and getting set up and synced correctly. Other then becoming familiar with the set up everything was straight forward as I knew what files I would be creating

2. What design decisions or changes did you make?

The main change I made in this step was actually the main title of the program. I decided to go with something more straight forward and directly related to the purpose of the program, " Just Study" rather than choosing a title that could be misinforming.
